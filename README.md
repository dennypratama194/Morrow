# Morrow

Find the hours a spread-out team shares. When there are none, take turns, so the same person stops taking every late call.

- Free, no account, no backend. The team lives in the URL hash, which browsers never send to a server.
- Time zones and DST come from the browser's own tz database (`Intl`), for the week you pick.
- Export a weekly Google Calendar event, an `.ics`, or the whole rotation as staggered weekly events.

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # scoring, rotation, share links, calendar export
npm run build   # static site in out/
```

## How a slot is scored

Every half hour of your day is a candidate start. For each person, each hour of the meeting outside their working
hours counts against it, weighted by how far it falls from their working day (21:00 hurts more than 17:30). Hours
outside the time they said they'd stretch to count three times. Best times are the lowest totals.

For a weekly meeting, Morrow tries every set of 2 or 3 of the twelve best starts (at least an hour apart) and picks
the one that keeps the worst-off person's average lowest. It suggests a rotation only when that cuts the worst-off
person's share by at least a quarter, and never pushes someone outside their stretch hours to get there.

Code: `src/lib/plan.ts` (scoring, rotation), `src/lib/tz.ts`, `src/lib/share.ts`, `src/lib/ics.ts`,
`src/components/Globe.tsx` (canvas globe under the real sun line).

`src/lib/cities.ts` is generated by `node scripts/cities.mjs` from tzdata's `zone.tab`.
